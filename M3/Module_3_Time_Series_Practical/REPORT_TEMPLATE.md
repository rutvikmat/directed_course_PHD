# Practical Report

## Title
Comparative Time-Series Forecasting Using ARIMA, XGBoost and LSTM

## 1. Aim
To forecast hourly traffic volume using ARIMA, XGBoost and LSTM and compare
their predictive performance.

## 2. Dataset Description
The Metro Interstate Traffic Volume dataset from the UCI Machine Learning
Repository contains hourly traffic-volume observations and associated
calendar and weather information. The prediction target is `traffic_volume`.

## 3. Tools and Libraries
Python, pandas, NumPy, Matplotlib, statsmodels, scikit-learn, XGBoost and TensorFlow/Keras.

## 4. Methodology
1. Load and sort observations by timestamp.
2. Convert timestamps and target values to suitable data types.
3. Reindex observations to hourly frequency and interpolate missing target values.
4. Split the data chronologically into training and testing portions.
5. Fit ARIMA to the training time series.
6. Create lag, rolling and calendar features for XGBoost.
7. Train LSTM on historical sequences and generate recursive forecasts.
8. Evaluate each model on common test timestamps.

## 5. Model Descriptions
### ARIMA
ARIMA models temporal dependence using autoregressive and moving-average
components, with differencing to address nonstationarity.

### XGBoost
XGBoost is a gradient-boosted decision-tree method. Lagged observations,
rolling statistics and calendar variables are used as predictors.

### LSTM
LSTM is a recurrent neural network architecture designed to learn sequential
dependencies through gated memory units.

## 6. Evaluation Metrics
MAE, RMSE, MAPE and R-squared are used. Lower MAE/RMSE/MAPE indicate lower
prediction errors; higher R-squared generally indicates better fit.
